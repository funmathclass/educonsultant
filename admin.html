Gagal masuk?
  1. Tombol Google membuka halaman verifikasi Google sebentar. Di sana, klik Lanjutkan ke Dashboard.
  2. Pastikan browser login dengan akun Google admin. Punya beberapa akun? Pilih tautan akun ke-2 di halaman verifikasi, atau pakai jendela Incognito.
  3. Cadangan: aktifkan login kata sandi di Apps Script → Project Settings → Script Properties, tambahkan ADMIN_PASSWORD (minimal 8 karakter), lalu muat ulang halaman ini.

Alamat admin tidak lengkap

Buka dashboard lewat alamat rahasia admin (berakhiran admin.html#k=…). Lihat alamatnya dengan menjalankan fungsi lihatAlamatAdmin di editor Apps Script.
