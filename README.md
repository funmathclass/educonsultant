# Portofolio — frontend GitHub Pages

Frontend statis untuk portofolio. Backend: Google Apps Script (`Kode.gs`, dikirim terpisah).
Mulai dari **PANDUAN-INSTALASI.md**. Isi `js/config.js` sebelum push.

- `index.html` halaman publik · `admin.html` dashboard (dibuka dengan alamat rahasia)
- `css/` gaya · `js/` logika · `fonts/` font & ikon (self-host)
